MON ASSISTANT

    
Mon assistant personnalisé

    
Un modèle personnel, c'est un nom et des consignes permanentes posés sur un modèle de base déjà existant. Aucun poids d'IA n'est téléchargé ni entraîné ici.


    

      
ÉTAPE 1 · NOM

      
      
Le nom affiché dans SIMIA pour reconnaître ce modèle.

    


    

      
ÉTAPE 2 · MODÈLE DE BASE

      
      
Le moteur qui réfléchit. Choisissez un modèle léger sur un petit appareil, ou un modèle « Documents » si vous interrogez des PDF.

    


    

      
ÉTAPE 3 · CONSIGNES PERMANENTES

      
      
Ce que SIMIA doit toujours faire dans ce modèle. Ces consignes sont ajoutées à chaque conversation qui utilise ce modèle.
