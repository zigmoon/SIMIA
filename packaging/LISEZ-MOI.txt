SIMIA Desktop
=============

Archive : {{TARGET}}

Lancement
  1. Decompressez l'archive ou vous voulez (aucun droit administrateur).
  2. Lancez simia-desktop (double-clic, ou ./simia-desktop dans un terminal).
  3. L'interface s'ouvre sur http://127.0.0.1:8170. Au premier message,
     SIMIA telecharge le modele choisi (une seule fois), puis tout se passe
     sur la machine : le reseau peut etre coupe.

Selon votre systeme
  Windows  SmartScreen peut demander une confirmation : "Informations
           complementaires" puis "Executer quand meme". Le runtime Visual C++
           dont l'application a besoin est inclus dans l'archive : rien a
           installer.

  macOS    Le binaire n'est pas signe. Au premier lancement, macOS le bloque :
             xattr -dr com.apple.quarantine .
           puis relancez. La generation d'images demande un Mac Apple Silicon ;
           sur Mac Intel, la conversation et l'atelier de code fonctionnent
           normalement, sans le bouton Image.

  Linux    chmod +x simia-desktop avant le premier lancement. Vulkan est
           utilise s'il est disponible, sinon le processeur prend le relais.
           Le lanceur demande glibc 2.35 (Ubuntu 22.04 et plus recent) ; la
           generation d'images demande 2.38, soit Ubuntu 24.04, car le binaire
           sd-server vient de l'amont. Conversation et code marchent des 22.04.

Ce que contient cette archive
  simia-desktop        le lanceur : il sert l'interface et pilote les moteurs
  web/                 l'interface complete
  vendor/              les moteurs d'inference (llama.cpp, et
                       stable-diffusion.cpp quand la plateforme en a un)
  models/              les catalogues, et le style Gravure SIMIA (LoRA 6 Mo)

Modeles
  Le catalogue pointe vers un CDN : les poids se telechargent au premier choix
  et restent dans models/. Ils peuvent etre supprimes pour liberer de l'espace.

  Pour ajouter un modele qui n'est pas au catalogue, deposez n'importe quel
  fichier .gguf compatible llama.cpp dans models/ puis relancez : il apparait
  dans la bibliotheque, avec son nom et sa quantification lus dans le nom du
  fichier. Aucune liste blanche, aucune limite de taille imposee par SIMIA :
  c'est la memoire video de la machine qui decide.

Version bureau ou version web
  La version web (https://app.zigmoon.com/SIMIA/) s'installe depuis le
  navigateur et sert a essayer : elle est plafonnee a 1,9 Go par modele, parce
  qu'un onglet ne dispose que d'une fraction de la memoire du GPU.

  Cette version bureau est la version complete. Elle fait tourner les modeles
  volumineux (7, 14, 32 milliards de parametres, jusqu'a 9,7 Go de poids par
  fichier), genere des images jusqu'a 1024 px, et accepte n'importe quel .gguf
  supplementaire depose dans models/.
