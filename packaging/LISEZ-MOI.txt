SIMIA Desktop
=============

Archive : {{TARGET}}

Lancement
  1. Decompressez l'archive ou vous voulez (aucun droit administrateur).
  2. Lancez simia-desktop (double-clic, ou ./simia-desktop dans un terminal).
  3. L'interface s'ouvre sur http://127.0.0.1:8170. Au premier message,
     SIMIA telecharge le modele choisi (une seule fois), puis tout se passe
     sur la machine : le reseau peut etre coupe.

Selon votre systeme
  Windows  Windows affiche un avertissement au premier lancement : le programme
           n'est pas signe par un certificat de signature de code. Ce n'est pas
           un virus, le programme est compile par GitHub Actions a partir du
           code source publie sur GitHub.

           Pour ne PAS voir l'avertissement : avant de decompresser l'archive,
           clic droit sur le .zip, Proprietes, cocher "Debloquer", puis OK.
           Windows oublie ainsi que le fichier vient d'Internet, et
           simia-desktop.exe demarre directement.

           Si l'avertissement apparait quand meme : "Informations
           complementaires", puis "Executer quand meme".

           Le runtime Visual C++ dont l'application a besoin est inclus dans
           l'archive : rien a installer, aucun droit administrateur.

  macOS    macOS 13.3 (Ventura) ou plus recent est necessaire : le moteur de
           conversation est compile pour cette version et macOS refuse de
           charger un binaire plus recent que le systeme.
           Le binaire n'est pas signe. Au premier lancement, macOS le bloque :
             xattr -dr com.apple.quarantine .
           puis relancez.
           La generation d'images demande en plus macOS 26, et il n'existe de
           moteur d'images que pour Apple Silicon. Sur Mac Intel le bouton
           Image est donc masque : la conversation, les documents et l'atelier
           de code fonctionnent normalement.

  Linux    chmod +x simia-desktop avant le premier lancement. Vulkan est
           utilise s'il est disponible, sinon le processeur prend le relais.
           Ubuntu 22.04 ou plus recent suffit pour la conversation (glibc 2.34).
           La generation d'images demande glibc 2.43, donc Ubuntu 26.04 : les
           binaires sd-server de l'amont sont compiles la. Sur une distribution
           plus ancienne le bouton Image echoue au demarrage du moteur, sans
           affecter la conversation.

Ce que contient cette archive
  simia-desktop        le lanceur : il sert l'interface et pilote les moteurs
  web/                 l'interface complete
  vendor/              les moteurs d'inference (llama.cpp, et
                       stable-diffusion.cpp quand la plateforme en a un)
  models/              le catalogue, le style Gravure SIMIA (LoRA 6 Mo) et un
                       modele d'image deja pret (SD 1.5, 1,46 Go) pour que le
                       bouton Image fonctionne des le premier lancement, sur
                       Windows, Mac Apple Silicon et Linux. Sur Mac Intel,
                       l'archive pese donc 25 Mo et non 1,4 Go : ni moteur, ni
                       modele d'image, puisque le moteur d'images de l'amont
                       n'est publie que pour Apple Silicon.

Modeles
  Le catalogue pointe vers un CDN : les poids se telechargent au premier choix
  et restent dans models/. Ils peuvent etre supprimes pour liberer de l'espace.
  Un modele de conversation (Qwen 2.5 Coder 0.5B, 469 Mo) est telecharge au
  tout premier lancement, avant que la fenetre ne s'ouvre : le pourcentage
  defile dans la fenetre noire, c'est normal. Ensuite, chaque modele choisi se
  telecharge depuis la bibliotheque, avec sa barre de progression.

  Pour ajouter un modele qui n'est pas au catalogue, deposez n'importe quel
  fichier .gguf compatible llama.cpp dans models/ puis relancez : il apparait
  dans la bibliotheque, avec son nom et sa quantification lus dans le nom du
  fichier. Aucune liste blanche, aucune limite de taille imposee par SIMIA :
  c'est la memoire video de la machine qui decide.

Version bureau ou version web
  La version web (https://app.zigmoon.com/SIMIA/) s'installe depuis le
  navigateur et sert a essayer : elle est plafonnee a 1,9 Go par modele, parce
  qu'un onglet ne dispose que d'une fraction de la memoire du GPU.

  Cette version bureau est la version complete. Elle fait tourner les modeles
  volumineux (7, 14, 32 milliards de parametres, jusqu'a 9,7 Go de poids par
  fichier), genere des images jusqu'a 1024 px, et accepte n'importe quel .gguf
  supplementaire depose dans models/.
