Questions fréquentes

Ce qu'il faut savoir avant d'installer.

Quelle différence entre la version web et la version desktop ?

La version web exécute le modèle dans votre navigateur via WebGPU : pratique pour essayer, mais limitée aux modèles sous 1,9 Go. La version desktop lance le moteur directement sur le GPU de la machine, sans plafond de navigateur : elle accède aux modèles de code les plus gros et à la génération d'images jusqu'à 1024 px.

La version web peut-elle s'installer comme une application ?

Oui. Sur Chrome et Edge, un bouton Installer SIMIA apparaît dans l'interface : l'application obtient son icône et sa propre fenêtre, sans barre d'adresse. Sur iPhone et iPad, passez par Safari puis Partager → Sur l'écran d'accueil. L'interface est ensuite mise en cache : elle s'ouvre même sans réseau.

Faut-il une carte graphique puissante ?

Pas obligatoirement. Une carte récente accélère énormément les réponses (une RTX 2060 suffit pour la génération d'images), mais SIMIA retombe automatiquement sur le processeur. Prévoyez alors davantage de mémoire et un peu de patience.

Où sont stockés les modèles ?

Chaque modèle est téléchargé une seule fois depuis un CDN puis conservé dans le dossier models/ de l'application. Vous pouvez les supprimer ou les déplacer à tout moment.

La génération d'images est-elle filtrée ?

SIMIA n'applique aucun filtre de contenu : il exécute les modèles ouverts que vous choisissez, sans modération ajoutée. À vous d'en faire un usage responsable et conforme à la loi de votre pays.

Pourquoi les paquets ne sont-ils pas signés ?

Les versions sont produites par GitHub Actions à partir du code source. Sur macOS, il faut autoriser l'application au premier lancement ; sur Windows, SmartScreen demande une confirmation. Aucun droit administrateur n'est requis.
